# Komari GFW

Komari 1.6.1 的跨境 TCP 连通性监测插件。每台选中的服务器通过已有 Agent 主动探测 3 个大陆目标和 2 个非大陆目标；连续满足规则时，使用 Komari 系统通知渠道发送疑似被墙及恢复通知。

> 这是连通性异常推断，不是对封锁原因的确证。路由故障、DNS、目标服务或本机出站策略也会影响结果。

## 已确认范围

- 原生服务端插件 ZIP，不修改 Komari 核心和 Agent，不执行远程 shell。
- 5 个可自定义目标，支持 `IPv4:端口`、`域名:端口` 和 `[IPv6]:端口`。
- 自选参与监测的服务器，按稳定的服务器 UUID 保存选择。
- 大陆 3 个全部失败、非大陆至少 1 个成功时连续确认告警；非大陆可改为必须 2 个成功。
- 已告警服务器连续 5/5 全部成功后才解除被墙状态。
- IPv4 可选择隐藏后两段，例如 `203.0.113.25` 显示为 `203.0.*.*`。
- 在 Komari 后台“插件功能”中提供总览状态页及配置页。
- 可选严格模式：选择一个或多个境内 Komari Agent，反向探测每台受检服务器的指定 TCP 端口；双向大陆链路全失败才告警，正反向全部恢复才解除。
- 状态持久化、重复结果去重、数据过期保护、通知重试及任务生命周期管理。

## 当前阶段

2026-11-02：0.1.0 已实现基础与严格模式、总览和配置页。已在官方 Komari 1.6.1 Windows 宿主验证安装、两路反向探针、告警/恢复、系统 Webhook、持久化和界面。Agent 为合成 v2 协议客户端，TCP 使用本地回环真实连接；未连接生产实例，也未进行跨地域实测。详见 `docs/TESTING.md`。

## 默认目标

```text
大陆电信  gd-ct-v4.ip.zstaticcdn.com:80
大陆联通  gd-cu-v4.ip.zstaticcdn.com:80
大陆移动  gd-cm-v4.ip.zstaticcdn.com:80
非大陆    1.1.1.1:443
非大陆    9.9.9.9:443
```

以上是可修改的默认配置，不保证目标始终可用。首次安装监测关闭；需选择服务器并保存启用。默认大陆目标同处广东，建议按实际需要修改槽位以增加地域独立性。

## 构建与安装

需要 Node.js 24+（测试直接执行 TypeScript），无需在 Komari 服务器上安装 Node.js。

```sh
npm ci
npm run check
npm run audit:public
```

构建生成 `dist/komari-gfw-0.1.0.zip` 和 `dist/SHA256SUMS`。在 Komari 插件管理上传 ZIP，批准系统 RPC / 路由权限，启用后进入“插件功能 / GFW 配置”。详细步骤见运维文档。

严格模式需要选择一个或多个已接入 Komari 的境内探针，并填写每台受检服务器的测试端口；必须已有可接受连接的服务，插件不开放防火墙和端口。
