## 自动化范围

- 地址校验、固定 3+2 目标、仅选择的服务器参与、IPv4 后两段及 IPv6 脱敏。
- 全局/逐台开关四种组合、旧严格与普通配置迁移、无效方向草稿保留、端口按需必填、手动/IPv4/IPv6 优先级、地址变化与逐台签名隔离；混合节点按自己的方向独立告警与恢复。
- 基础模式 32 种、双境内正向探针严格模式 128 种连通性组合，各覆盖非大陆至少一个/全部成功两种门槛；完整样本、连续确认、重放去重、陈旧数据和告警保留。
- 反向墙/正向墙/双向墙、普通表述、方向切换独立确认、不重发当前方向、不因单向好转解除、恢复时记录原方向与完整异常时长；通知无末尾说明。
- 任务所有权、移除无用任务、暂停/清理、配置冲突、双槽持久化损坏恢复、通知重试及标题。
- 插件“被墙检测”、功能“被墙检测总览”、统一配置入口、正确方向说明、没有重复页头导航。
- 历史事件数量/时间上限、有效待发消息保留、过期历史不解除告警。
- 聚合记录清理仅涉及所属任务的两项 Ping 指标；近期桶、仍在聚合的桶、其它任务与非 Ping 指标不变。空归属、重命名任务、截断响应、不兼容表结构及无效前缀不执行删除；删除批量有上限。
- 退休保护期与原始样本核验、旧隐藏证据保留、字典回收、用户/其它指标字典保留、失败重试；删除部分完成、重载、重新启用取消待删、改名撤销归属、最后节点删除清空映射和全部自有任务。
- 精确实例标记、相似用户名称、旧任务发现/重建/ID 复用、退休 ID 跨重启保留，普通和严格模式生命周期中的过滤与内部原始取数。
- 后台任务列表尾斜杠及查询字符串、原生空/错误响应、用户字段不变；限定 GET 范围，写方法及无关 RPC 不修改，不支持的分页结构显式错误。
- 历史先过滤后采样、用户任务完整摘要、跨任务 `basic_info`、数组 `count`、空/填充指标系列、非 Ping 指标和其它 RPC 不变。
- RPC 单条/批量/乱序/重复 ID/null/无 ID、位置参数/标量参数、Go JSON 字段大小写及 Unicode 折叠、HTTP 请求头伪造、错误/未知分页明确失败、关联缓存容量与回收。
- WebSocket 文本与二进制帧的选择、关联与关闭清理；100000 条合成记录的过滤与不修改原数据检查。
- 删除受检服务器/境内探针/最后节点、普通/严格/暂停状态、部分探针删除与只剩自身、过期设置表单、升级及重载；清除选择/端口/状态/过期正向任务，保留用户任务与存活告警。
- 完整列表中的离线节点不删除，RPC 错误、畸形条目、重复 UUID 和未知分页包装不清理配置；成功空列表（含原生 null）则清理全部已删除选择。新增节点不自动加入。
- 一次性调整提示 8 秒自动消失、隐藏页面不提前确认、网络失败重试不重显、相同文字的新事件重新提示；已读确认持久化且不改变配置修订号，过期或不匹配确认不清除新提示，真实错误不随定时器隐藏。

SQL 单元测试使用 SQLite 执行公共语法并检查各驱动参数绑定。它不等于 MySQL/PostgreSQL 实例验证。

## 本地宿主测试

`scripts/host-test.mjs` 启动官方 Komari 1.6.1 Windows 二进制，使用随机回环端口、随机凭据与一次性数据目录，不接受生产地址或凭据。

- ZIP 安装、权限批准、MoeJS 加载、管理员鉴权和写入防跨站。
- 1 台双向受检服务器、2 台境内探针，额外加入仅反向受检节点测试混合配置；真实回环 TCP 连接，经 v2 `agent.pingResult` 上报和原始指标查询产生告警/恢复。
- 严格模式三种方向、方向变化及全部恢复，本地系统 Webhook 的标题/方向证据、无说明段落及 IP 脱敏。
- 插件启停、持久化、通知去重；从旧 ZIP 覆盖升级保留配置、任务 ID 和历史。
- 真实后台配置、原生总览菜单、保存/刷新、受检/探针搜索、长列表内部滚动、隐藏字段的必填取消及草稿恢复、1400 像素桌面与 390 像素移动端、无页面错误和整页横向溢出。
- 注入本地合成聚合历史，验证仅清理插件过期行、保留用户任务及近期行。
- 节点删除后不留空绑定任务；加速退休保护期的本地 SQLite 空序列字典回收，不影响用户指标。
- 匿名和已登录公开 REST/RPC、管理员任务 REST/RPC、批量混合方法、匿名/管理员 WebSocket 文本/二进制消息；用户记录和统计保持，内部样本仍用于告警。
- 真实原生延迟监测任务/服务器视图及选择器、普通绑定编辑和 CRUD；测试仅在一次性 SQLite 宿主用管理员数据库 RPC 只读检查原始任务，生产插件不增加取原始任务的旁路接口。
- 普通 REST 的 Upgrade 头旁路反例；不关闭 Origin 校验，WS 测试使用真正的同源浏览器。

测试只操作自身进程及隔离 Edge，不使用用户浏览器资料。结束后停止服务并删除一次性宿主目录；截图和简要结果位于忽略的 `.local/`，检查完删除。

## 复现

```sh
npm ci
npm run check
npm run audit:public
```

宿主测试另需官方 1.6.1 二进制及 Edge。二进制放入 `.local/komari.exe` 或以 `KOMARI_TEST_BINARY` 指定，然后执行 `npm run test:host`。将 `KOMARI_TEST_UPGRADE_FROM` 设为旧 ZIP 路径可复现升级测试；结果记录宿主实际返回的版本，不写死宿主必须精确等于 1.6.1。当前 Upgrade 旁路反例断言针对 1.6.1，未来宿主修正后需相应更新这个反例测试。

Windows 沙箱可能阻止独立 Edge 启动，此时需在允许启动隔离浏览器的环境运行完整宿主测试；不能把浏览器启动失败当成功。

## 验证边界

尚未连接用户生产实例、真实大陆/境外 Agent 或用户通知渠道；回环测试不是跨地域验收。未验证默认公网目标的持续可达性、用户 Agent 版本、实际 DNS/防火墙、长期负载、真实断电、Linux 宿主及外部 MySQL/PostgreSQL 清理。CI 覆盖 Linux/Windows 的类型检查、单元测试和构建，不运行宿主测试。
