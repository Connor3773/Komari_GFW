# 验证计划与记录

## 单元测试

- 地址：域名、IPv4、括号 IPv6、端口范围、重复目标、空值、URL/路径/凭据注入、非法主机。
- 隐私：IPv4 后两段隐藏，IPv6 脱敏，消息中不含 token、UUID Client 自动补全或未脱敏 IP。
- 组合：大陆 0/3 与非大陆 0/2、1/2、2/2；大陆部分通；全部 5/5。
- 连续确认：初始正常不发恢复、阈值边界、抖动中断、已告警部分恢复不解除。
- 样本：重复、乱序、旧数据、未来时间、缺一目标、查询失败、跨周期拼接、聚合结果拒绝。
- 持久化：重启去重、发送前落盘、有限重试、配置变化、队列容量。
- 任务：仅选择服务器、default_on=false、删除后找回、暂停、用户任务保护。
- API：匿名、Agent、非管理员拒绝；写操作防跨站；错误信息不暴露敏感对象。
- 严格模式：一个/多个境内探针、排除自身、测试端口必填、地址变化后重新采样、反向成功阻止告警、反向失败/缺失阻止恢复、不同目标之间结果隔离。

## 宿主与界面

- 使用官方 Komari 1.6.1 在本地回环地址启动隔离测试实例，不连接生产服务器。
- 安装生成 ZIP，确认 manifest、权限批准、全局生命周期和独立数据目录。
- 管理员登录后打开总览和配置，验证保存、状态渲染、搜索、筛选和移动端布局。
- 使用测试 Agent/RPC 数据验证采样；测试通知发往本地测试通道，不发往用户真实渠道。
- 模拟测试不代替真实 Agent 网络探测；没有完成的项目明确标注待验证。

## 复现

```sh
npm ci
npm run check
npm run audit:public
```

宿主测试需另外从官方发布获取 Komari 1.6.1 二进制，并安装 Edge。将二进制放入被 Git 忽略的 `.local/komari.exe`（或通过 `KOMARI_TEST_BINARY` 指定），执行 `npm run test:host`。此命令只启动本地回环隔离实例，不接收生产地址或凭据。测试结束自动停止自身服务和删除临时宿主目录；截图及简要结果保留在 `.local/` 便于检查，确认后可删除。

复现升级测试时，将环境变量 `KOMARI_TEST_UPGRADE_FROM` 设为旧版 ZIP 路径，再执行同一命令；测试先安装旧包并产生配置和历史，然后上传当前版本并断言数据保留。
